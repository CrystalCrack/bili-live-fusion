# 三路融合姬

一个运行于 Microsoft Edge 的 Manifest V3 扩展，将两个 Bilibili 直播间的**实时画面、音频和弹幕**融合到同一块直播画布。

**输出是连续的实时音视频流。** 调整布局、裁剪、音量和弹幕规则时，独立输出窗口随即更新；整个过程无需录制或后期转码。录制 WebM 和截图属于独立的附加功能。

## 安装与启动

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 打开「开发人员模式」，选择「加载解压缩的扩展」。
3. 选择本项目的 **`extension` 文件夹**，该文件夹内有 `manifest.json`。
4. 点击工具栏中的「三路融合姬」图标，进入工作台。可先点「体验演示」直接操作两路动态演示源。

### 更新后打开

- 在 `edge://extensions` 找到「三路融合姬」，点击卡片上的重新加载按钮，再点击扩展图标。
- 当前版本为 **0.1.1**。点击图标会直接打开工作台；启动页中也提供「进入融合工作台」按钮。
- 也可右键扩展图标，选择「扩展选项」打开工作台。
- 如果此前加载的是另一个位置的解压文件夹，请重新加载本工作区的 `extension` 文件夹。

无需安装项目依赖，也无需构建即可加载扩展。安装后，刷新已经打开的 Bilibili 直播间，使内容脚本加载到页面中。

## 实时使用流程

1. 输入 A / B 的房间号或完整直播链接，点击右侧图标分别打开直播间，并在原页面开始播放。
2. 在两个源卡片中分别点击「采集直播间」，在浏览器弹窗里选择**对应的标签页**，勾选「同时分享标签页音频」。每路采集均由用户明确授权。
3. 通过下拉菜单为 A / B 关联对应的直播间标签页，以读取、发送弹幕。采集与关联应选择同一页面。
4. 点击「识别播放器区域」去掉页面边框，或点「框选裁剪」在源画面中直接选择区域。
5. 选择左右 / 上下二分、画中画、单路或自由布局。拖动画面移动、拖动边角缩放；属性栏可精确编辑百分比坐标。
6. 选择 A、B 或 A+B 音频和弹幕，在「直播输出」里打开实时播放窗口。

### 将融合结果继续直播

- **在浏览器直接观看**：独立输出窗口持续播放合成后的实时音视频，可全屏或画中画。输出窗口默认关闭声音，可手动打开；工作台的「本机监听」控制工作台声音。
- **使用 OBS 推流**：在 OBS 中添加「窗口采集」，选择「三路融合姬 · 直播输出」窗口；使用支持的窗口音频采集 / 应用程序音频采集接入该窗口声音。若使用桌面音频采集，需避免同时采入工作台监听与原直播间声音。OBS 配置直播平台的推流地址后即可发送融合直播。
- 浏览器扩展负责实时合成与播放，OBS 负责 RTMP / RTMPS 平台推流；两者之间没有先录制再处理的步骤。项目不读取或保存直播平台的推流密钥。

## 已实现功能

### 画面

- 两个独立标签页的实时采集，可分别连接、重连、断开。
- 原生 Canvas 2D 实时合成；左右二分、上下二分、画中画、仅 A、仅 B、自由布局。
- 自由拖动、四角缩放、边缘 / 中心吸附；方向键微调，Shift 加速，Alt 暂停吸附。
- 可视化框选裁剪、百分比裁剪、基于关联页面播放器位置的自动裁剪。
- 等比完整显示、等比填满、拉伸铺满；不透明度、显示隐藏、层级、位置交换。
- 横屏 1080p / 720p、竖屏、方形画布，24 / 30 / 60 FPS 与自定义背景色。

### 音频

- A、B、A+B、全部静音；单路音量、静音、左右声像、0–2000 ms 音频延迟。
- Web Audio 混音、主音量、实时电平、本机监听、主输出限幅。
- 「语音增强」使用 150 Hz 高通、4.2 kHz 低通与动态压缩，改善人声可辨度。它是频段处理，并非 AI 人声 / 伴奏分离。
- 混合音频作为实时输出流的音轨传送；输出窗口关闭不会断开输入源。

### 弹幕

- 内容脚本跟随直播页面 DOM 读取新消息，按 A / B 区分来源。
- 仅 A、仅 B、A+B、关闭；画布显示开关和消息列表。
- 关键词、用户名 / UID、受限正则过滤；8 秒跨源去重、每秒速率限制。
- 字号、不透明度、滚动时长、显示区域、来源和用户名显示。
- 可选择 A、B 或同时向两个房间提交弹幕，复用原页面已登录的会话，提供发送间隔和字数检查。

### 输出与场景

- **实时输出窗口**：Canvas 流 + 混合音轨经本机 WebRTC 传递，BroadcastChannel 只传递本机连接信令；无中转服务器，无 STUN / TURN 服务。
- 输出全屏 / 画中画、手动音频开关、断线重连。
- 附加 WebM 录制、PNG 截图。录制文件在停止后通过保存按钮下载。
- 本机自动保存、命名场景、导入 / 导出 JSON、恢复默认。
- 内置动态演示画面、低音量合成音轨、演示弹幕，方便不打开直播间时体验完整流程。

## 权限与隐私

扩展仅声明：

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存布局、音频和弹幕设置 |
| `https://live.bilibili.com/*` | 查找、关联 Bilibili 直播标签页；读取页面新弹幕并操作发送输入区 |

音视频由浏览器原生分享弹窗授权。无摄像头、麦克风、Cookie、下载管理、远程服务权限，不把画面或音频上传到服务器。导出的场景不包含授权令牌或音视频。

## 实现约束

- 采集标签页与弹幕关联标签页由用户分别指定，浏览器不会向网页暴露被分享标签页的 ID。关联与采集请保持一致，避免按其他页面的播放器位置裁剪。
- 弹幕来源为页面新渲染的 DOM 节点，不重放历史消息，也不是官方全量弹幕协议客户端。Bilibili 页面结构变化时，可调整 `extension/content.js` 中的节点选择器。
- 发送弹幕通过关联页面现有的输入框和发送按钮提交，登录、风控、禁言、房间权限及发送结果由平台控制。
- 原直播间播放器和工作台同时出声时可关闭「本机监听」。采集时已请求浏览器抑制被采集页的本地播放；不要静音整个标签页，以免一起静音被采集音轨。
- 录制在内存中积累到停止后生成 WebM。长时间直播建议直接交给 OBS 录制 / 推流。
- 真正的 AI 人声分离、虚拟摄像头 / 麦克风、浏览器内直推 RTMP 不属于当前版本实现。

## 开发

使用 Node.js 20+。扩展运行部分无第三方依赖。

```powershell
npm run preview     # http://127.0.0.1:4173 ，可体验演示与实时输出
npm test            # 模型、坐标、裁剪、过滤规则测试
npm run check       # 语法、清单、资源、CSP、产品文案检查
npm run package     # 检查、测试后打包扩展 ZIP
```

浏览器集成测试使用 Playwright 与已安装的 Edge。安装 Playwright 后，**先在单独终端启动 `npm run preview`**，再运行：

```powershell
npm install --no-save playwright
node scripts/browser-smoke.mjs
node scripts/extension-smoke.mjs
```

也可用 `PLAYWRIGHT_PATH` 指定已有的 Playwright 模块目录，用 `EDGE_PATH` 指定 Edge 可执行文件路径。测试输出与临时浏览器配置保存在被 Git 忽略的 `artifacts/` 中。

测试分别覆盖：

- 模型单元测试：输入校验、导入清洗、布局坐标、裁剪几何、过滤、去重、限流和正则安全。
- 工作台浏览器测试：两路动态采集源、音轨、电平、布局拖动、裁剪、混音、实时输出接收、WebM 播放、截图、场景保存和窄屏布局。
- 解压扩展集成测试：在 Edge 加载真实 MV3 扩展，使用本机拦截的 Bilibili 页面夹具检验 Service Worker、内容脚本、弹幕读取、输入提交、发送间隔和播放器裁剪。测试不会向真实直播间发送消息。
- 启动入口测试：实际打开扩展工具栏弹出页，检查首次打开工作台、再次点击复用已有标签页，并测试标签页关闭、窗口聚焦错误和重试操作。

```text
  manifest.json           Edge / Chromium MV3 清单
  background.js           入口、直播间列表与消息路由

  studio.html / .js       工作台
  styles.css              界面样式
  output.html / .js / .css 实时输出播放器
  lib/
    model.js              场景、布局、坐标与过滤规则
    audio.js              Web Audio 混音
    renderer.js           实时画布与弹幕渲染
    crop-editor.js        可视化源裁剪
    output-channel.js     本机实时 WebRTC 输出

tests/                    模型单元测试
```
