# 0.3.10 · 修复网页融合播放被暂停

用户提供的 0.3.9 播放信息显示：两路输入持续播放，合成帧持续增长，本机媒体连接已建立，网页视频源仍为融合流，视频已就绪却处于 paused 状态。此前仅收到媒体数据就显示 playing，无法准确反映网页视频是否正在播放。这份信息定位到了暂停状态，未直接给出触发暂停的调用来源。

- 应用融合场景时主动启动播放，不继承原播放引擎留下的暂停状态。
- 接管目标视频的 play / pause 调用，隔离页面程序暂停；保留原生控件及播放快捷键触发的主动暂停和继续。用户暂停期间，背景播放调用不会改变其意图。
- 监听视频的播放、暂停和缓冲事件；出现非主动暂停时恢复播放。播放器替换视频元素时沿用用户的播放意图。
- 视频实际开始播放后才显示正在播放。浏览器要求用户点击时显示“点击 B 站播放按钮启动融合直播”，保留连接等待用户操作，避免反复发起播放请求或触发启动超时。
- 播放信息新增 wantPlaying、playBlocked、lastPlayError 和最近 12 条播放事件；blocked.pause 记录页面程序暂停被拦截的次数。诊断仅保留在当前页内存，由用户主动复制。

## 更新后使用

1. 在 Edge 扩展管理页重新加载扩展，确认版本为 0.3.10。
2. 刷新已打开的 B 站直播页，使网页播放脚本更新。
3. 点击插件 →“在当前直播页播放”或“应用最新配置”。
4. 页面提示启动播放时，点击 B 站原生播放按钮。
5. 如仍出现闪屏或持续加载，打开插件小窗，点击“复制播放信息”并反馈。

## 检查范围

按用户安排执行快速代码与单元检查，覆盖初始暂停、页面反复暂停、主动暂停与继续、视频元素替换、浏览器播放拒绝和真实播放状态转发；实际直播由用户试用反馈。
