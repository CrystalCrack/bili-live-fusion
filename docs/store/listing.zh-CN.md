# bili直播融合姬 · Edge 商店文案

## 名称

bili直播融合姬

## 简短说明（已同步到 manifest）

三路 + 一路 = 二路。将两个 Bilibili 直播间的画面、声音和弹幕实时融合，自由布局、选择画质、混音对轴，边看边互动。

## 详细介绍（复制以下正文）

三路 + 一路 = 二路。
把喜欢的两个现场，融在一起。

bili直播融合姬是一款面向 Bilibili 双直播间观看与实时编排的 Edge 扩展。输入两个直播间的房间号或链接，即可直接接入直播画面、音频和弹幕，在同一个播放页面中边看边调整。

【画面自由拼】
左右二分、上下二分、画中画、单路或自由布局，按自己的习惯组合两个现场。支持移动、缩放、裁剪、层级与透明度调整，也可以只保留每个直播间中想看的区域。每路可单独选择平台提供的直播画质。

【声音一起听】
选择只听 A、只听 B，或同时混合两路声音，分别调整音量。通过整路延后与声音微调，对齐两路直播的画面和声音，让一起观看更顺手。

【弹幕一起聊】
融合两路实时弹幕，按来源、关键词、正则表达式等规则筛选。观看页提供弹幕列表与 A / B 来源切换；悬停画面弹幕可高亮停留，复制或 +1 发回原房间。自己发送的弹幕以金色突出显示，发送目标可选 A、B 或 A+B。

【专心看直播】
工作台用来调整，观看页用来欣赏。左侧一键切换，保留当前设置。普通模式提供大画面与右侧弹幕栏，全屏模式将控件和发送框融入画面底部，静置后自动收起。

【放进网页看】
点击插件图标，在小窗中选择打开工作台，或将已保存的场景应用到当前 Bilibili 直播页。网页模式按保存的布局、裁剪、画质、混音和对轴设置生成实时融合流，接入 B 站原生播放器，继续使用原生控制栏、全屏、暂停、音量和网页弹幕；随时恢复原直播。配置完成后，网页播放可独立于工作台运行。

【实时输出与场景保存】
持续输出融合后的直播画面、混合音频与弹幕，可供 OBS 采集推流。场景自动保存在本机，支持导入、导出，也提供本地录制与截图功能。连接后即可实时观看和输出。

【开始使用】
1. 点击扩展图标，打开工作台。
2. 输入 A、B 房间号或直播链接，连接直播间。
3. 选择画质、布局、声音与弹幕规则。
4. 切换到“观看”，或开启直播输出接入 OBS。

音视频融合与场景保存均在本机完成。直播与弹幕连接直接访问 Bilibili 及其直播资源服务；发送弹幕使用当前 Edge 配置中已登录的 Bilibili 账号。画质选项由直播间和当前账号返回。请在授权范围内使用与分享直播内容。
