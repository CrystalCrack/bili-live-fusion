# 0.3.0 观看页面验证

## 功能与实现

工作台顶部新增「进入观看」。独立 watch.html 以本机 WebRTC 持续接收融合视频与混音，不使用录制文件。工作台调整实时应用于观看画面。原直播输出窗口保留给采集推流使用。

观看页的弹幕通过同源、带随机会话标识的本机通道接收。工作台输出一条没有画布弹幕的实时画面，观看页用 DOM 和 Web Animations 叠加已通过过滤的弹幕，避免同一条弹幕在视频和互动层重复出现。

悬停或键盘聚焦弹幕后高亮、暂停该条动画，出现复制及 +1 操作。+1 原文发回来源房间；底部输入栏独立选择 A、B 或两房。实际发送复用工作台的登录身份、CSRF、同房间去重及 5 秒限频，按服务结果显示成功或失败。

全屏目标是包含画面、控制栏和发送栏的播放器容器，双击画面和全屏按钮均可切换。观看页支持暂停 / 继续、声音、音量、弹幕开关、键盘快捷键、回工作台、重连和窄屏布局。观看时工作台本机监听暂停，关闭观看页后按原设置恢复；混音输出不受影响。
