# 0.3.2 · 清新界面与交互优化

## 界面

- 雾白背景、薄荷绿主色、柔紫色 B 路，统一工作台、扩展入口、弹窗与观看聊天栏。
- 调整卡片圆角、间距、文字层级、表单与按钮，使主要操作更突出。
- 连接 → 编排 → 观看三步导航，编排区可跳转到布局、音频、弹幕。
- 中等窗口将画面属性与输出设置置于下方；窄窗口纵向排列并保留双路源卡片。
- 观看画面继续使用深色背景，聊天栏使用浅色，显示播放快捷键。

## 交互

- 「连接全部」只接入尚未连接且已填写有效房间号的来源；连接中按钮显示当前动作。
- 连接状态附带可访问性信息，失败原因在卡片中换行显示。
- 属性区可直接切换 A / B，源预览支持键盘选择。
- 工作台弹幕增加字数计数、可用目标、发送状态与结果；发送中输入的新文字会保留。
- 房间号回车操作避开输入法组字过程；观看快捷键也跳过输入法组字。
- 保留原生视频图层、同页观看切换和实时直播管线。

## 本轮检查与体验交接

按照用户要求，本轮只执行脚本语法、扩展资源引用、清单、产品文案及差异格式检查；未运行浏览器自动化、直播或长时间播放测试。

体验方法：关闭旧工作台，在 Edge 扩展管理页重新加载扩展，再打开工作台，确认 v0.3.2。可先体验演示，再连接日常使用的直播间，重点查看桌面与窄窗口布局、工作台 / 观看切换和弹幕输入体验。
