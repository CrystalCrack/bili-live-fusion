# 0.3.3 · 导航与操作入口统一

- 左侧导航只负责页面切换，仅保留「工作台」「观看」，窄窗口也持续显示。
- 场景管理移到工作台顶部，与使用指南归入工作台工具；弹出操作使用独立工具按钮。
- 输出设置归入工作台分区，与布局、声音、弹幕共用分区定位操作。
- 移除顶部「进入观看」、流程条观看按钮、播放器内返回按钮和空状态返回按钮；观看页面的进出统一通过左侧导航。
- 顶部流程条调整为静态操作说明，不再混用页面切换和分区跳转。
- 直播输出、使用指南、体验演示各保留一个操作入口。
- 品牌区域作为标识展示，避免误点击刷新并打断直播连接。
- 同步使用说明与已有浏览器脚本中的入口定位；实时视频和音频处理方式保持原样。

本轮仅执行代码语法、扩展资源与文案、差异格式检查。按用户偏好，页面操作与实际播放由用户体验后反馈。
