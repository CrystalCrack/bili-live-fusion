# 0.3.6 · 使用 B 站原生播放器观看融合直播

- 点击插件图标先显示小窗，选择“打开工作台”或“在当前直播页播放”。
- 按工作台已保存的房间、画质、布局、裁剪、透明度、层级、混音与音画对轴生成实时音视频流。
- 实时融合流接入 B 站原有的视频元素，保留原生播放器界面、控制栏、暂停、音量、全屏和网页弹幕。
- 网页模式不建立融合弹幕连接，不改动 Bilibili 的弹幕展示和发送逻辑。
- 合成在独立工作线程完成，直接传递媒体帧，使用保存的输出分辨率与帧率，不经过录制或二次视频编码。
- 两路解码与混音在本地扩展处理页运行，工作台可以关闭；同时打开时暂停其本机监听，减少重复声音。
- 从插件小窗“应用最新配置”重新接入，或选择“恢复原直播”退出融合。
- 通过短时、单次、绑定标签页的授权启动本地处理页，未增加主机域名或权限。

## 使用

1. 重新加载扩展，确认版本为 0.3.6，并刷新已打开的 B 站直播页。
2. 在工作台配置两个直播间、融合布局与声音，等待“场景已保存”。网页输出的清晰度与帧率使用工作台的输出设置。
3. 打开任意 Bilibili 直播间，等原生播放器就绪，点击插件 →“在当前直播页播放”。
4. 出现声音提示时点击“开启声音”，之后通过 B 站原生控制栏调整播放、音量和全屏。
5. 调整场景后回到网页，再次点击插件 →“应用最新配置”。
6. 点击插件 →“恢复原直播”退出网页融合。

本轮执行代码检查及场景、启动授权、原生媒体绑定和恢复单元检查。按用户要求，真实直播网页与全屏体验交由用户试用反馈。
