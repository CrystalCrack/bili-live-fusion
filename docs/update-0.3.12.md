# 0.3.12 · 网页融合 GPU 合成

## 更新内容

- 网页融合优先使用工作线程 WebGL2 着色器进行裁剪、缩放、透明度和图层混合，请求高性能图形处理器。
- 读取浏览器当前图形渲染器的名称与厂商。该信息反映浏览器实际使用的渲染器，不枚举系统所有显卡。
- 输入帧直接上传为纹理；没有新输入帧时复用纹理。继续沿用逐帧确认、有限队列和单调直播时钟。
- 编码协商优先请求 H.264，同时保留其他可协商编码格式；最终硬件和软件编码器由 Edge 决定。
- 插件小窗新增加速信息，显示合成方式、当前渲染器、编码器名称、实际分辨率、帧率与码率。编码效率标记与图形渲染器分开报告。
- WebGL2 不可用或运行时上下文重置时切换通用合成；不重新连接输入直播或改变场景设置。
- 显卡与编码诊断只在本地内存中使用；隐私说明同步更新。权限清单不变。

## 试用

1. 在 Edge 扩展管理页重新加载，工作台版本为 v0.3.12。
2. 刷新普通 B 站直播页，点击插件并应用已保存场景。
3. 播放几秒后再次打开插件小窗，查看加速信息；可用“复制播放信息”反馈完整采样。
4. 对比相同画质、分辨率和帧率下的流畅度。工作台观看继续直接呈现原视频；本次优化针对网页融合合成阶段，实时重编码过程仍然存在。

按既定协作方式完成快速代码与单元检查，真实直播表现由用户试用反馈。

## 本机快速检查结果

- 88 项单元检查和 36 个脚本静态检查通过。
- 使用独立测试页面在 Edge 核对 WebGL2 着色器及 VideoFrame 输入输出，浏览器返回 AMD Radeon RX 9070 XT / Direct3D11；四个色块的上下方向与颜色一致。
- 该检查只确认本机图形渲染路径和像素传递，未测量真实直播持续播放的帧率提升。
