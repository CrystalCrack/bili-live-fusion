# 0.3.7 · 修复网页融合启动超时

- 修复网页融合停在“连接响应超时，请重新应用场景”的问题：本地处理页直接读取并核验一次性启动授权，不再等待后台消息回复。
- 保留授权有效期、当前标签页、B 站直播地址、扩展身份与处理页地址校验，核验通过后消费授权。
- 分别显示授权读取、场景读取、原生播放器连接步骤；发生错误时保留具体原因，不再被后续总超时覆盖。
- 保留 B 站原生播放器、控制栏与网页弹幕，继续只替换实时音视频流。

## 更新后使用

1. 在 Edge 扩展管理页重新加载扩展，确认版本为 0.3.7。
2. 刷新已打开的 B 站直播页。
3. 点击插件 →“在当前直播页播放”。工作台已保存的场景继续使用。

增加授权启动回归检查，包括后台消息始终不回复、跨标签页、授权过期、重用授权和各阶段超时。按用户安排，仅进行快速代码与单元检查，实际直播由用户试用反馈。
