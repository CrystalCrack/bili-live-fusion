# 0.2.1 连接修复验证

## 原问题与修复范围

问题报告：84074 一直显示「连接中」。独立配置访问该真实房间可以连接；原工作台的具体停点未取得。代码检查发现，旧连接流程在获取播放信息之前等待 AudioContext.resume()，且前台消息没有截止时间。

修复后的流程在点击时建立声音图，同时启动声音激活与直播连接；声音启动等待超过 3 秒后显示「启用声音」。后台播放信息超过 20 秒后结束等待并恢复操作。播放器实际触发 playing 后才显示「直播中」，播放点击限制可通过「继续播放」恢复。

连接信息保留最近 50 条阶段事件、版本、房间、画质、播放器进度、声音状态和弹幕计数。数据留在工作台内，复制由用户点击触发。
