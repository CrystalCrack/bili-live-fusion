# 0.3.8 · 修复网页融合的克隆错误与切流闪烁

- 移除扩展处理页与直播网页之间的可传输媒体流，改用本机 WebRTC 媒体连接。跨页面仅交换 SDP/ICE 连接信息，音视频不经过消息对象克隆。
- 融合画面仍在独立工作线程实时生成，按已保存的输出分辨率与帧率发送。网页模式会进行实时编码和解码，视频发送码率上限为 40 Mbps，并优先保持设定分辨率；没有先录制再处理的步骤。
- 工作线程与本地视频轨之间采用显式帧转移和处理确认，限制在途帧数。输出使用单调实时时钟，避免两路源时间戳不同、对轴跳转或重连造成输出停滞。
- 同时等待融合首帧生成与接收视频轨就绪，再交给 B 站原生视频元素；保留原生界面、暂停、音量、全屏以及网页弹幕。
- 连接失败时停止融合并恢复原直播，保留恢复按钮和具体错误，阻止迟到消息再次切流。
- 不新增扩展权限，不配置 STUN/TURN 或外部媒体中转服务器。

## 更新后使用

1. 在 Edge 扩展管理页重新加载扩展，确认版本为 0.3.8。
2. 刷新已打开的 B 站直播页，使网页脚本更新。
3. 点击插件 →“在当前直播页播放”，或“应用最新配置”。

本次按用户安排进行快速代码与单元检查，包括本机连接协商、首帧交接、原播放器恢复、帧处理确认和输出时间戳；真实直播由用户试用反馈。

此版本替换了 0.3.6 发布说明中的网页媒体帧直接传递方案，网页模式现在采用实时媒体编码。
