# 0.3.4 · 观看页参考样式调整

按用户提供的普通直播页与全屏截图，调整观看布局与播放器交互。

- 普通模式采用大画面、简洁房间信息条与右侧聊天栏。保留清新浅色外框，发送按钮使用柔粉色。
- 原文字控制按钮换成播放、音量、画面弹幕、聊天侧栏、全屏图标，悬浮于画面底部。
- 聊天列表使用真实接入且经过现有规则过滤的弹幕，支持全部 / A / B 筛选、历史滚动、新消息提示和复制 / +1。
- 自己发送的消息保留金色，并在列表中标记「我」。+1 发送到原消息的来源房间。
- 发送表单只有一份。普通模式放在侧栏底部；收起侧栏时放到画面下方；全屏时融入画面底部悬浮控制区。
- 全屏隐藏房间信息与侧栏；静置后隐藏控件和发送框，输入或互动时保持显示。退出全屏恢复之前的侧栏选择。
- 窄窗口把聊天区放到视频下方，避免压缩视频宽度。
- 保留原有解码节点、裁剪几何与 Web Audio。侧栏最多保留 150 条消息，按帧批量更新；工作台、全屏和收起侧栏时只缓存记录，停止列表 DOM 更新。

本轮按用户偏好只做基础代码检查，实际页面体验由用户反馈。
