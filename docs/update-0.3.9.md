# 0.3.9 · 完善网页融合的视频源接管

- 修复上一版本接管遗漏的源设置入口。融合期间，对目标视频的 src、srcObject、属性设置与删除、load、currentTime 和 playbackRate 写入进行接管，包括网页提前缓存的原型方法，阻止原播放引擎在融合播放期间重启加载。
- 仅保护当前融合视频元素，其余媒体元素保持原行为。原生播放、暂停、音量、全屏与网页弹幕继续使用；退出时释放接管，恢复最新的原直播地址、播放速度和用户当前的暂停状态。
- 当前视频仍在播放器内时保持绑定，不因其他视频短暂出现而切换。网页真正替换视频元素时再重新接入。
- 合成工作线程按保存帧率持续输出最新画面，在输入短暂停顿时维持媒体输出；处理确认限制在途帧数量。源恢复时使用新画面，采集轨失活或读取完成后可重新建立。
- 插件小窗新增“复制播放信息”，包含本机连接状态、源是否仍为融合流、原引擎重载拦截次数、输入和输出帧数。记录仅保留在当前页内存，点击后复制到剪贴板。

## 更新后使用

1. 在 Edge 扩展管理页重新加载扩展，确认版本为 0.3.9。
2. 刷新 B 站直播页，使网页中的接管脚本更新。
3. 点击插件 →“在当前直播页播放”或“应用最新配置”。
4. 如需反馈播放状态，打开插件小窗，点击“复制播放信息”。

按用户安排，仅执行快速代码和单元检查，模拟网页重复改源、原型方法重载、播放器元素替换、暂停恢复、输入断帧与采集轨重建；真实直播由用户试用反馈。
